# 2027年度入試DB 公開検索ポリシー v0.1

基準日: 2026-09-29。対象ブランチ: `reaudit-2027-v0.1`。

## 収録と掲載は別の判断

canonical Masterへの収録条件は、大学公式資料により `1 row = 1 actual application unit / selection slot` の粒度と主要項目を確定できること。これを満たす行は公開状態 `confirmed` として、従来の検索・詳細レコードに投影する。Masterへ推測行を作らない。

公開検索への掲載条件は、**2027年度にその選抜が存在する、または実施予定であることを大学公式情報で確認したこと**。出願単位や詳細が未確定でも選抜の存在を見つけられるよう、`data/publication/provisional_admissions_2027.csv` に個別審査した公開事実を記録する。UpdateQueueは作業管理であり、その全行を自動公開しない。第三者DBは候補照合に使い、公開根拠には使わない。

検索結果にないことは、原則として選抜が存在しないことを示さない。`No` は公式資料で条件がないと確認できた場合だけ、`Unknown` は判断材料不足の場合だけに使う。公開状態はこれらの条件値とは別の軸である。

## 公開状態

| 状態 | 根拠と表示 |
| --- | --- |
| `confirmed` | actual application unitと主要情報を確定したMaster行。通常の検索結果。 |
| `details_pending` | 2027年度の実施は確認済み。出願単位、併願または詳細条件が未確定。「2027年度実施確認済み・詳細確認中」と公式リンクを表示。 |
| `previous_year_reference` | 2027年度の実施を確認し、詳細要項は未公開。2026年度公式資料へのリンクを参考として併記し、「前年実績（2026年度）であり、2027年度は変更される可能性があります」を必ず表示。前年の条件を当年度値へコピーしない。 |
| `publication_pending` | 2027年度の実施計画または公開予定を公式に確認。詳細要項の公開待ち。予定時期と公式掲載ページを表示。認可等の条件付き実施はその条件を明示する。 |

## データと生成

- 版付き入力Schema: `schema/publication/provisional_admissions_schema_v0_1.json`。
- 公開用入力: `data/publication/provisional_admissions_2027.csv`。公式URL、確認日、既知範囲、未確定範囲、前年資料URL、関連UQ IDを保存する。UQ IDは該当する作業項目がある場合にだけ設定する。
- `build_site_data` は既存のSQLite→Site-data v0.3投影後、別の `provisional_admissions.json` と `public_discovery_manifest.json` を生成する。manifestに入力CSV・SQLite・UpdateQueueのSHA-256と公開件数、生成物のSHA-256を記録する。SiteはSQLite SHAが一致し、生成物のハッシュと件数が合う場合だけ読み込む。
- canonical、Unified contract、SQLite Schema、既存Site-data v0.3 Schemaは変更しない。確定行と暫定選抜の件数を混ぜない。

## 重複と検索条件

公開用入力は一つの選抜の存在を示すレコードであり、募集人員表の行数や志望可能数を表さない。生成時に同一大学・同一選抜名・同一学部等がSQLiteの確定行にあれば暫定表示を抑制する。学部等が未指定の暫定レコードは、同一大学・同一選抜名の確定行があれば抑制する。名称が異なる複雑な重複は入力審査で確認する。

Siteの暫定選抜は、大学名と大学種別という確認済みの識別条件だけで除外する。それ以外の検索条件は適合を判定せず、「指定された詳細条件への適合は未判定」と表示する。確定済み募集単位の検索件数・詳細フィルター・候補エクスポートには混入させない。確定行が0件でも暫定選抜がある場合は、結果ページにその選抜と公式リンクを表示する。

## 2026-09-29時点の初期公開範囲

北海道教育大学の学校推薦型、帯広畜産大学の私費外国人留学生、金沢大学医学類のKUGS特別枠、小樽商科大学昼間の私費外国人留学生、茨城大学地域未来共創学環の私費外国人留学生、琉球大学の社会人・帰国生徒・私費外国人留学生、東京薬科大学生命科学部の社会人、東海大学の留学生一般選抜を個別審査した。北海道教育大学はactual application unit未確定の回帰fixtureとする。帯広畜産大学・小樽商科大学・琉球大学の前年資料は参考リンクだけを表示する。金沢大学の特別枠は文部科学省認可待ちであることを明示する。

残るUpdateQueueの公開候補は、公式2027資料の対象選抜・既存Masterとの包含関係・公開URLを個別に確認してからこの入力に追記する。Queueをクローズする作業と公開掲載は独立して進める。
