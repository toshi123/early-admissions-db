# 公開検索UI・条件判定 v0.2

基準: 2026-09-29 の `reaudit-2027-v0.1`、公開ポリシー v0.1。canonical Master の収録条件と provisional の公開条件は `docs/public_discovery_policy_v0_1.md` に従う。Masterや既存Site-data v0.3 Schemaは変更しない。

## 同じ結果一覧

確定募集単位と provisional を大学ごとの同一結果一覧に置く。件数は「検索結果 N 件（確定済み募集単位 A 件・詳細確認中 B 件）」とし、B を actual application unit の件数として扱わない。provisional は公開状態、未確定事項、大学公式リンクを明示する。前年資料は2026年度参考と明示する。生成時と表示時に同一大学・選抜名・学部等の確定行との重複を抑制する。

## 検索条件

- 学校推薦型・総合型は初期状態で両方対象。片方だけにもできる。両方OFFで特別選抜も未選択なら検索を止め、「少なくとも1つ選抜方式を選択してください」と表示する。
- 帰国生、IB、私費外国人留学生、社会人は初期状態で対象外。選択すると選んだ特別選抜のいずれかを検索する。この場合、学校推薦型・総合型のチェックより特別選抜指定を優先する。確定行の4フラグはSQLiteから生成した版付き `special_selection_index_schema_v0_1.json` の派生索引で判定する。索引はSite-dataと同じSQLiteハッシュ、行数、行ID、JSONハッシュを照合する。
- provisional の方式と特別選抜の識別は、従来CSVを残したまま `provisional_admissions_2027_v0_2.csv` に審査済みタグを記録する。留学生一般選抜は私費外国人留学生と断定せず `unclassified_international` とする。私費外国人留学生フィルタでは判定不能として注記付きで残す。その他の留学生一般を安全に分類するには、出願資格・在留区分・学費負担などの公式根拠を持つ別の版付き分類が必要。
- 出願締切は `YYYY-MM-DD` の当年度値だけで日付比較する。指定日以上は一致、早い確定日付は不一致、空欄・形式不明・前年参考は判定不能として結果に残す。検索画面では指定日を日付入力で設定する。
- 「あなたの評定平均」は、条件なしを一致、単純な全体評定下限を数値判定し、Unknown・科目別・追加条件・前年参考は判定不能として結果に残す。追加条件があれば全体数値を満たしても適格とは確定しない。旧共有URLの評定安全照合は互換のため維持する。

大学・都道府県・学問分野・共通テスト・研究活動など既存の確定行フィルタは維持する。provisional は大学・大学種別・版付きで確定した方式／特別選抜タグ以外、条件の真偽を推測せず注記付きで残す。検索結果は出願資格の保証ではない。
